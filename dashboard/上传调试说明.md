# 🔧 上传功能调试指南

## 问题诊断步骤

### 第一步：打开浏览器控制台

1. 按 `F12` 或右键 → 检查
2. 切换到 "Console"（控制台）标签
3. 刷新页面

### 第二步：查看初始化日志

页面加载后，控制台应该显示：
```
DOM 元素初始化完成
elements.uploadArea: <div id="uploadArea">...</div>
elements.fileInput: <input type="file" id="fileInput">
初始化上传处理...
上传处理初始化完成
```

**如果看不到这些日志** → JavaScript 文件未正确加载

### 第三步：测试上传

**方式 A：点击上传区域**
1. 点击"上传 Excel 数据文件"区域
2. 选择文件 `20260316-20260322_作业数据.xlsx`
3. 查看控制台日志

**方式 B：使用调试按钮**
1. 点击"🔧 选择文件（调试模式）"按钮
2. 选择文件
3. 查看控制台日志

**方式 C：拖拽上传**
1. 拖拽文件到上传区域
2. 松开鼠标
3. 查看控制台日志

### 第四步：查看控制台日志

**正常流程应该显示：**
```
点击上传区域

开始解析 Excel 文件：20260316-20260322_作业数据.xlsx
文件解析成功，共 3 条记录
✓ 已上传：20260316-20260322_作业数据.xlsx (3 条记录)
```

### 第五步：常见问题

**问题 1：点击上传区域无任何反应**
- 检查控制台是否有错误信息
- 确认 `elements.fileInput` 是否存在
- 尝试点击调试按钮

**问题 2：选择文件后无反应**
- 检查文件选择对话框是否弹出
- 查看控制台是否有 "文件选择变化触发" 日志
- 确认文件是否为 `.xlsx` 格式

**问题 3：显示"文件格式不正确"**
- 确认文件名格式：`YYYYMMDD-YYYYMMDD_描述.xlsx`
- 正确示例：`20260316-20260322_作业数据.xlsx`
- 错误示例：`3 月数据.xlsx`

**问题 4：显示"解析失败"**
- 检查 Excel 文件是否损坏
- 确认文件包含必要的列（省份、城市、班级 id 等）
- 查看控制台详细错误信息

## 快速修复

如果上传仍然不工作，尝试：

1. **强制刷新页面**
   - Mac: `Cmd + Shift + R`
   - Windows: `Ctrl + Shift + R`

2. **清除浏览器缓存**
   - 打开开发者工具 (F12)
   - 右键刷新按钮 → 清空缓存并硬性重新加载

3. **检查浏览器兼容性**
   - 推荐使用 Chrome 90+
   - 确保 JavaScript 已启用

4. **检查文件权限**
   - 确保 HTML 文件可以读取
   - 确保可以访问本地文件
