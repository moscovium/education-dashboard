# 🚀 快速启动指南

## 3 分钟上手数据看板

### 第一步：打开看板

**方式 1：直接双击**
```
在文件管理器中双击 dashboard/index.html
```

**方式 2：本地服务器（推荐）**
```bash
cd /Users/x/Downloads/Project/dashboard
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

### 第二步：上传数据

1. **找到你的 Excel 文件**
   - 格式：`20260316-20260322_作业数据.xlsx`

2. **拖拽上传**
   - 将文件拖到"每周数据上传"区域
   - 或点击区域选择文件

3. **确认上传成功**
   - 看到"已上传的周次数据"列表中出现新卡片
   - 显示记录条数

### 第三步：筛选查看

1. **选择时间段**（必选）
   - 开始日期：2026-03-16
   - 结束日期：2026-03-22

2. **选择地区**（可选）
   - 省份 → 城市 → 区县 → 学校 → 年级
   - 级联选择，逐级解锁

3. **点击"应用筛选"**

### 第四步：查看结果

- **指标卡片**：总览核心数据
- **趋势图表**：4 个维度的周趋势
- **数据表格**：按班级 ID 排序的明细

### 第五步：导出数据

- 点击表格上方的"导出 CSV"
- 保存筛选后的数据

## 📋 数据格式速查

### 必填字段（Excel 列名）

| 字段 | 用途 |
|------|------|
| 省份 | 地区筛选 |
| 城市 | 地区筛选 |
| 区县 | 地区筛选 |
| 学校名称 | 地区筛选 |
| 年级 | 筛选 |
| **班级 id** | **跨表关联核心字段** |
| 班级名称 | 显示 |
| 教师姓名 | 显示 |
| 总学生数 | 统计 |
| 布置作业次数 | 统计 |
| 作业完成率 | 统计 |
| 作业得分率 | 统计 |
| 作答平均耗时/min | 统计 |

### 文件命名

```
格式：YYYYMMDD-YYYYMMDD_描述.xlsx

✅ 20260316-20260322_作业数据.xlsx
✅ 20260323-20260329_weekly.xlsx
```

## 💡 核心功能

### 1. 每周上传窗口
- 显示所有已上传的周次
- 每个卡片显示日期范围和记录数
- 点击"×"可删除某个周次

### 2. 班级 ID 关联
- 系统自动根据"班级 id"关联历史数据
- 表格默认按班级 ID 排序
- 可追踪同一班级的跨周表现

### 3. 级联筛选
- 省份 → 城市 → 区县 → 学校 → 年级
- 逐级解锁，精确筛选

### 4. 数据持久化
- 上传后刷新页面数据不丢失
- 数据保存在浏览器本地
- 清除缓存会丢失数据

## ❓ 快速排障

| 问题 | 解决方法 |
|------|---------|
| 文件上传失败 | 检查文件名格式 |
| 筛选无结果 | 确认日期范围覆盖文件日期 |
| 数据不显示 | 检查 Excel 列名是否匹配 |
| 筛选选项灰色 | 需要先选上一级 |
