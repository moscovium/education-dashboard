# 教育数据看板 - 使用指南

## 📊 核心功能

本看板用于监测学校和班级的**转化率**与**作业完成情况**（布置作业次数、作业完成率），支持按周次上传数据并通过班级 ID 进行跨表关联分析。

### 核心指标
- 📊 **转化率**：平均转化率
- 📈 **布置作业次数**：累计布置作业数量
- ✅ **作业完成率**：平均作业完成比例

### 可视化图表
1. **组合图**：柱状图（布置作业次数）+ 折线图（作业完成率）
2. **转化率趋势图**：折线图展示转化率变化趋势

---

## 📋 数据格式

### Excel 文件命名

**格式：** `YYYYMMDD-YYYYMMDD_描述.xlsx`

**示例：**
- `20260316-20260322_作业数据.xlsx`
- `20260323-20260329_周数据.xlsx`

### 必填字段

| 字段 | 说明 | 用途 |
|------|------|------|
| 省份 | 省份名称 | 筛选 |
| 城市 | 城市名称 | 筛选 |
| 区县 | 区县名称 | 筛选 |
| 学校名称 | 学校全称 | 筛选 |
| 年级 | 年级名称 | 筛选 |
| **班级 id** | 班级唯一标识 | **跨表关联** |
| 班级名称 | 班级名称 | 展示 |
| 总学生数 | 学生总数 | 统计 |
| **转化率** | 转化率数值 | **核心指标** |
| **布置作业次数** | 作业布置次数 | **核心指标** |
| **作业完成率** | 作业完成率 (%) | **核心指标** |

## 🚀 使用步骤

### 1. 打开看板

双击 `index.html` 或启动本地服务器：
```bash
cd /Users/x/Downloads/Project/dashboard
python3 -m http.server 8080
# 访问 http://localhost:8080
```

### 2. 上传数据

1. 点击"上传 Excel 数据文件"区域
2. 选择或拖拽 Excel 文件
3. 系统自动解析文件名中的日期范围
4. 上传成功后显示在"已上传的周次数据"列表中

**上传提示：**
- ✅ 支持批量上传多个文件
- ✅ 自动检测重复文件
- ✅ 显示解析记录数
- ✅ 支持删除已上传周次

### 3. 筛选数据

**时间段：** 选择起止日期
**地区筛选：** 省份 → 城市 → 区县 → 学校 → 年级（级联）
**应用筛选：** 点击按钮查看结果

### 4. 查看结果

**指标卡片：**
- 转化率（%）
- 布置作业次数（次）
- 作业完成率（%）
- 覆盖学校数
- 覆盖班级数
- 学生总数

**组合图：**
- 左侧 Y 轴：布置作业次数（柱状图）
- 右侧 Y 轴：作业完成率（折线图）
- X 轴：周次

**转化率趋势图：**
- 展示各周转化率变化

**数据表格：**
- 按班级 ID 和周次排序
- 显示所有字段明细

### 5. 导出数据

点击"导出 CSV"按钮，保存筛选后的数据。

## 📊 数据查询示例

### 示例：查看某学校两周内作业完成情况

1. **上传文件：**
   - `20260316-20260322_作业数据.xlsx`
   - `20260323-20260329_作业数据.xlsx`

2. **设置筛选：**
   - 时间段：2026-03-16 至 2026-03-29
   - 省份：甘肃省
   - 城市：白银市
   - 区县：白银区
   - 学校：白银市白银区第四小学

3. **查看结果：**
   - 组合图显示两周的作业布置次数和完成率对比
   - 转化率趋势图显示转化率变化
   - 表格显示各班级详细数据

## ⚠️ 注意事项

### 文件命名
```
✅ 正确：20260316-20260322_作业数据.xlsx
❌ 错误：3 月第三周.xlsx
❌ 错误：2026-03-16 至 2026-03-22.xlsx
```

### 数据一致性
- 同一班级的"班级 id"必须保持一致（用于跨周关联）
- 同一学校的"学校名称"必须完全一致

### 上传问题排查
- **上传无反应**：检查浏览器控制台（F12）是否有错误
- **解析失败**：确认文件为.xlsx 格式且包含必填字段
- **数据不显示**：检查日期范围是否覆盖文件日期

## 🔧 技术说明

- **Excel 解析**：SheetJS (xlsx)
- **图表库**：ECharts 5.4
- **日期处理**：Day.js
- **数据存储**：localStorage（刷新不丢失）
- **适用场景**：中小规模数据（单次 <50,000 条）

## 📝 常见问题

**Q: 上传后刷新页面数据还在吗？**
A: 数据元数据会保存，但文件需要重新上传（浏览器安全限制）。

**Q: 组合图如何解读？**
A: 蓝色柱状图表示作业布置次数（左轴），绿色折线表示作业完成率（右轴）。

**Q: 班级 ID 有什么用？**
A: 班级 ID 是跨周追踪同一班级表现的关键字段，系统按班级 ID 关联历史数据。

**Q: 为什么筛选选项是灰色的？**
A: 筛选是级联的，需先选择上一级（如先选省份才能选城市）。

**Q: 如何删除已上传的数据？**
A: 在"已上传的周次数据"列表中点击周次卡片右上角的"×"。
