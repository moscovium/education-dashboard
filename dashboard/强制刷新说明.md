# 🔄 强制刷新浏览器缓存

## 问题原因

如果测试页面 (`test-upload.html`) 可以正常工作，但主页面 (`index.html`) 点击按钮无反应，这通常是因为**浏览器缓存了旧版本的 JavaScript 文件**。

## 解决方案

### 方法 1：强制刷新（推荐）

**Windows / Linux:**
```
Ctrl + Shift + R
```
或
```
Ctrl + F5
```

**Mac:**
```
Cmd + Shift + R
```

### 方法 2：清除缓存并硬性重新加载

**Chrome / Edge:**
1. 按 `F12` 打开开发者工具
2. 右键点击刷新按钮（地址栏左侧的 🔄）
3. 选择"清空缓存并硬性重新加载"

**Firefox:**
1. 按 `Ctrl + Shift + Delete` (Windows) 或 `Cmd + Shift + Delete` (Mac)
2. 选择"缓存"
3. 点击"立即清除"

**Safari:**
1. 按 `Cmd + Option + E` 清除缓存
2. 按 `Cmd + R` 刷新页面

### 方法 3：禁用缓存（开发模式）

**Chrome / Edge:**
1. 按 `F12` 打开开发者工具
2. 切换到 "Network"（网络）标签
3. 勾选 "Disable cache"（禁用缓存）
4. 保持开发者工具打开状态

**Firefox:**
1. 按 `F12` 打开开发者工具
2. 点击右上角的齿轮图标 ⚙️
3. 勾选 "Disable HTTP Cache"（禁用 HTTP 缓存）

### 方法 4：使用无痕/隐私模式

**Chrome:** `Ctrl + Shift + N` (Windows) 或 `Cmd + Shift + N` (Mac)
**Firefox:** `Ctrl + Shift + P` (Windows) 或 `Cmd + Shift + P` (Mac)
**Safari:** `Cmd + Shift + N`

然后在无痕窗口中访问 `http://localhost:8080`

## 验证是否成功

刷新后，页面右下角应该显示版本号，例如：`v2.1.2`

控制台应该显示：
```

🔍 开始初始化 DOM 元素...
✅ DOM 元素初始化完成

触发文件选择对话框
...
```

---

## 如果仍然不工作

1. **检查浏览器版本** - 确保使用最新版本的 Chrome/Firefox/Safari
2. **尝试其他浏览器** - 有时某个浏览器可能有特殊问题
3. **检查控制台错误** - 按 F12 查看是否有 JavaScript 错误
4. **重启本地服务器** - 停止并重新运行 `python3 -m http.server 8080`
